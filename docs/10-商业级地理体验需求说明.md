| 项 | 现状（`docs/01-产品说明.md`） | 本轮调整（用户 2026-11-10 明确） |

## 三、需求说明

### TA-R01 分块 LOD 地形（放大后仍有真实细节）

- **简要说明**：地形按瓦片分级加载，相机拉近时自动换用更精细的高程网格，不再放大同一张全局高度图。
- **角色**：户外爱好者、地理爱好者。
- **前置条件**：页面完成首屏加载；数据源已确定且合规。
- **主过程**：
  1. 用户进入页面，系统加载覆盖亚洲 / 全球的粗级别瓦片并渲染首帧。
  2. 用户滚轮放大，系统按相机距离与视锥计算所需级别，加载并切换到更细瓦片。
  3. 视野内瓦片连续拼接，山脊、沟谷、坡面保持连续，无空洞、无共面穿插、无矩形色块。
  4. 用户缩小，系统释放高层级瓦片，回到粗级别。
- **分支过程**：平面模式与地球（球面）模式使用同一套级别判定；覆盖区与全球粗层的归属沿用 `aOverlay` 规则。
- **异常过程**：瓦片请求失败或超时 → 保留上一级别画面并给出可重试提示，不得出现「Failed to fetch」式空白初始化；数据缺失区域回退到粗级别并明确标记。
- **后置条件**：当前视口内所有可见地形级别一致、边缘无缝，帧率不低于性能预算。
- **业务规则**：
  1. **公开发布版**精度遵守平面不优于 10 m、高程不优于 15 m、等高距不小于 20 m；**个人自用版**不受该公开精度上限约束，但仍不得使用涉密测绘成果，且界面须标注数据来源与实际精度，不得声称优于数据本身。
  2. 不得通过隐藏问题区域、磨平地形、关掉全球层 / 阴影 / AO 来「消除」异常。
  3. 瓦片是静态文件，可缓存、可校验 hash。
- **验收要点**：`12` 的 TC-01 / TC-02 / TC-03。

### TA-R02 真实感底图（晕渲 + 分层设色 + 影像）

- **简要说明**：在高度场上叠加预计算的多方向山体阴影 / 坡度专题层，并按运行模式接入允许的影像或矢量底图。
- **角色**：全部用户。
- **前置条件**：运行模式（`personal` / `public`）已确定；底图来源与 key 经用户拍板。
- **主过程**：用户切换「地貌 / 影像 / 混合」视图 → 系统按当前 LOD 取对应专题层与底图 → 分层设色随海拔连续过渡，阴影与坡面朝向一致，缩放时无跳变。
- **分支过程**：无 key 或离线 / 服务不可用时，降级为本地晕渲 + 分层设色，仍可用，不白屏。
- **异常过程**：底图服务跨域 / 配额 / 鉴权失败 → 提示原因并保留本地渲染，不阻塞地形；`personal` 模式下检测到公网可访问 → 提示切换 `public` 模式或关闭访问。
- **后置条件**：三种视图在平面与球面下均可用，图例与当前视图一致。
- **业务规则**：
  1. **运行模式**：`personal`＝个人自用、非公开、非商业；`public`＝任何不特定人可访问。默认 `personal`，但**必须同时满足「非公开可访问」**（仅 localhost / 内网 / 鉴权），否则一律按 `public` 处理。
  2. **`public` 模式**：底图**仅允许**腾讯地图 / 高德 / 百度 / 天地图（未指定时默认腾讯地图）；**禁止** Google Maps、Apple Maps、Bing 海外版、直连海外 OSM 瓦片、Mapbox、Leaflet+OSM 及无资质第三方源。
  3. **`personal` 模式**：可选 Google、Apple、Bing、OSM（公共或自托管）、Mapbox、天地图等；但**仍须遵守各厂商 ToS**——Google 禁止脱离其 SDK 使用瓦片与缓存、Apple 瓦片不得脱离 MapKit、OSM 须遵守 tile usage policy 与 attribution、Mapbox 受 token 与额度约束；**不得把可用 key 提交进仓库**。
  4. **两种模式都不放宽**：国界与中国台湾 / 中国香港 / 中国澳门 / 南海诸岛表达须正确；不标军事禁区与涉密实体；同一场景只用一个坐标系；无 key / 无网时降级本地晕渲。
- **验收要点**：TC-04 / TC-05 / TC-16 / TC-22 / TC-23。

### TA-R03a 户外决策图层（坡度角 / 坡向 / 等高线）

- **简要说明**：提供从 DEM 预计算的坡度角、坡向与等高线，把 3D 从「好看」变成「可读」。
- **角色**：徒步 / 爬山爱好者、地理爱好者。
- **前置条件**：地形数据已加载；图层开关可见。
- **主过程**：用户开启坡度角图层 → 系统按角度区间着色并在图例标明阈值；开启坡向 → 按方位着色；开启等高线 → 按不小于 20 m 的等高距绘制。
- **分支过程**：各图层独立开关，可叠加；平面与球面一致。
- **异常过程**：某级别缺少派生层 → 回退到上一级别并提示，不得用错误色带冒充。
- **后置条件**：图层与图例、当前 LOD、夸张比保持一致；关闭后完全还原。
- **业务规则**：
  1. 等高距 ≥ 20 m；不得展示优于 10 m 平面 / 15 m 高程精度的内容。
  2. 坡度 / 地形判断**必须显著标注免责声明**：不替代专业雪崩预报与现场判断，不承诺导航或救援安全。
  3. 夸张比改变时，坡度着色按真实高程计算，不受显示夸张影响。
- **验收要点**：TC-06 / TC-07a / TC-17。

### TA-R03b 线路与高程剖面（P2）

- **简要说明**：导入或绘制一条线路，展示距离 / 海拔 / 累计爬升剖面，支撑户外判断。
- **角色**：徒步 / 爬山爱好者。
- **前置条件**：R03a 已通过；线路数据格式与导入方式已评审。
- **主过程**：用户导入 GPX 或在地图上绘制线路 → 系统沿线采样高程 → 展示剖面与累计爬升 / 下降 → 可点击剖面定位到地图位置。
- **分支过程**：线路跨多个 LOD 级别时按真实高程采样，不随显示级别变化。
- **异常过程**：线路落在数据缺失区 → 剖面标记断点并说明，**不虚构高程**。
- **后置条件**：剖面数值可复现，单位与坐标约定明确。
- **业务规则**：
  1. 剖面必须基于真实高程，不受垂直夸张影响。
  2. 用户导入的 GPX 仅本地处理，不上传、不公开，遵守个人信息保护要求。
- **验收要点**：TC-07b / TC-17。

### TA-R04 市级行政区划浏览与检索

- **简要说明**：市级边界不再只在点选省份后出现，作为可独立开关的图层，可按 LOD 浏览、点选、检索并查看属性。
- **角色**：全部用户。
- **前置条件**：行政区划数据使用合规来源且完整。
- **主过程**：
  1. 用户在图层面板开启「市级行政区划」→ 系统按 LOD 绘制当前视野内的市界与市名。
  2. 用户点击某个市级单元 → 高亮该单元并弹出属性卡（名称、所属省级行政区、行政中心、主体地貌 / 海拔区间等**已核实字段**）。
  3. 用户点选省级区域 → 仍可展开该省全部市级单元（保留既有交互）。
  4. 用户在检索框输入市名 → 命中后相机飞抵并高亮。
- **分支过程**：小比例尺下只显示省级；大比例尺下显示市级；未开启图层时不绘制。
- **异常过程**：数据缺失的省级行政区 → 明确显示「暂无市级数据」，不得静默跳过整个省级行政区。
- **后置条件**：选中态唯一，取消选中后恢复；省级 / 市级 / 标注三层不互相遮挡。
- **业务规则**：
  1. 行政区划表达须符合国家标准地图，中国台湾、中国香港、中国澳门及南海诸岛不得缺失或错绘；`cities.json` 现缺台湾省、澳门特别行政区，须按合规来源补齐后再上线。
  2. 地名以依法公布的数据为准；重要地理信息数据以依法公布为准。
  3. 新增标注内容须纳入每六个月备案流程。
- **验收要点**：TC-08 / TC-09 / TC-15。

### TA-R05 山河结构化标注与详情

- **简要说明**：山峰、山脉、河流、湖泊从静态文字点 / 示意折线升级为带属性的结构化要素。
- **角色**：地理爱好者、户外爱好者。
- **前置条件**：要素数据集已建立并通过来源校对。
- **主过程**：用户放大到局部 → 按 LOD 出现山峰 / 河湖 / 山脉标注 → 点击要素 → 详情卡展示名称、类别、海拔或流向、所属山脉 / 流域等字段 → 可「飞抵此处」。
- **分支过程**：远景只显示一级要素（大江、主山脉），近景显示次级支流与山峰；境外要素弱化显示，重点始终是中国。
- **异常过程**：属性缺失的字段显示「暂无数据」，不得臆造数值。
- **后置条件**：详情卡可关闭，标注避让生效，视线不被遮挡。
- **业务规则**：
  1. 河流 / 铁路 / 公路不得继续以「示意性主干」冒充真实走向；正式版须换成权威路网 / 水系数据，并在文档中记录来源与精度。
  2. 交通主动脉标注名称并区分铁路 / 公路（用户前序明确要求），图层独立开关。
  3. 山峰海拔等数据须为依法公布或授权使用的数据。
- **验收要点**：TC-10 / TC-11。

### TA-R06 风景名胜 POI 分级与详情

- **简要说明**：景区 / 名胜按等级与 LOD 分级，可在放大局部看到标注，并有可查看详情。
- **角色**：旅游 / 徒步爱好者。
- **前置条件**：POI 数据集来源合规、字段可核验。
- **主过程**：用户放大到近景 / 超近景 → 逐级出现景区标注（图标 + 名称）→ 点击 → 详情卡展示等级、所在地、简介等字段 → 可加入「本次查看」列表或飞抵。
- **分支过程**：POI 可按类别（自然 / 人文 / 世界遗产 / 国家公园等）筛选；与城市、山河标注冲突时按优先级避让。
- **异常过程**：POI 过密 → 按 LOD 聚合 / 折叠，不叠字；点击聚合点展开列表。
- **后置条件**：筛选条件与图层开关状态可复现（URL 或本地状态）。
- **业务规则**：
  1. POI 数据不得包含他人私人位置数据；批量点数据遵守个人信息保护要求。
  2. 不得标注军事禁区、涉密实体、未公开敏感坐标。
  3. 新增 POI 标注纳入审图 / 备案流程。
- **验收要点**：TC-12 / TC-15。

### TA-R07 全局检索与地点跳转

- **简要说明**：一个检索入口可查省 / 市 / 山峰 / 河湖 / 景区，并飞抵定位。
- **角色**：全部用户。
- **前置条件**：R04–R06 的结构化数据集可用。
- **主过程**：用户输入关键词 → 系统给出分类结果列表 → 选择结果 → 相机飞抵并高亮 / 打开详情卡。
- **分支过程**：支持别名 / 简称时须标注对应关系；无结果时给出相近建议。
- **异常过程**：检索服务不可用时仅影响检索，不影响地图。
- **后置条件**：检索结果可关闭，地图状态可返回。
- **业务规则**：检索索引为静态构建产物，随数据版本一起校验 hash；不得引入需登录的第三方搜索服务。
- **验收要点**：TC-13。

### TA-R08 加载体验与性能预算

- **简要说明**：保留已有下载进度条，并让分块数据加载对用户可见、可预期。
- **角色**：全部用户。
- **前置条件**：CI 产物与线上一致。
- **主过程**：加载页显示真实已下载字节 / 百分比 → 首帧出现 → 后续 LOD 瓦片在后台加载，细级别就绪时平滑替换，不闪白。
- **分支过程**：慢网 / 中断 → 显示重试与已完成进度，不重复下载已缓存瓦片。
- **异常过程**：任一数据文件 404 / 解码失败 → 明确错误原因与资源路径，禁止只报「初始化失败：Failed to fetch」。
- **后置条件**：达到性能预算（具体阈值见 `11` §九，需评审确认）。
- **业务规则**：首屏只下载当前视野所需瓦片；静态文件名带内容 hash，可长期缓存；线上与本地产物可逐文件比对。
- **验收要点**：TC-14 / TC-18。

### TA-R09 信息层级与视觉细腻度

- **简要说明**：标注分级、避让、字体、图标、色彩与图例形成统一视觉系统，达到商业级观感。
- **角色**：全部用户。
- **前置条件**：`docs/05` 的 UI 信息架构约束继续生效。
- **主过程**：远景读地貌与阶梯，中景读省会与线路，近景读城市 / 山峰 / 景区，超近景读局部细节；同一档内按优先级占位，撞车时避让；图例随当前可见图层与视图联动。
- **分支过程**：面板折叠 / 窄屏时标注层同步解除裁切。
- **异常过程**：标注数量超过屏幕预算 → 降级低优先级，不出现文字堆叠。
- **后置条件**：平面 / 球面两种模式下层级一致。
- **业务规则**：新增任何图层必须同时加 store 键、面板开关与构建校验断言（`docs/02` 规则 6）；不得出现「永远显示、无法关闭」的元素。
- **验收要点**：TC-19。

### TA-R10 合规呈现（按运行模式）

- **简要说明**：`public` 模式补齐审图号 / 备案 / 来源；`personal` 模式改为「非公开声明 + 来源与精度 + 免责」，两种模式都不放宽领土表达。
- **角色**：项目方 / 审核方（`public`）、自用者（`personal`）、全部用户。
- **前置条件**：运行模式已确定；`public` 模式下审图号已办理、备案流程已建立。
- **主过程**：
  - `public`：页面左下角固定显示审图号与数据来源 → 坡度 / 线路附近显示免责声明 → 「关于」列出数据版本、来源、精度与备案记录。
  - `personal`：页面显示「个人自用 · 非公开发布」标识与数据来源 / 精度 → 免责声明 → 「关于」列出各底图厂商 attribution 与 ToS 说明。
- **分支过程**：`public` 审图号有效期两年，到期前触发复核；每六个月汇总新增标注内容送备案。
- **异常过程**：`public` 审图号未取得 / 过期 → **不得上线新增标注内容**；`personal` 检测到公网可访问 → 提示切换 `public` 模式或关闭公网访问。
- **后置条件**：合规项可逐条核验并留痕；`personal` 不得对外提供公开链接或搜索索引。
- **业务规则**：见 `09` §4.1 / §4.2；**领土表达在两种模式下都必须符合国家标准**；`public` 数据服务器在境内；`personal` 不得使用涉密测绘成果；`personal` 不得以「自用」为名对外发布。
- **验收要点**：TC-15 / TC-16 / TC-17 / TC-22。

### TA-R11 既有能力不回退

- **简要说明**：平面 / 地球双模式、全球地形、光照阴影、AO、导览、省份点选、夸张滑块、图层开关、指北针、自动旋转、进度条全部保留。
- **角色**：全部用户。
- **前置条件**：`07` / `08` 的回归基线可复跑。
- **主过程**：每次改动后按 `scripts/diag-baseline.js` 固定机位复测（真实 GPU、rAF 帧计数等待），对比近景 `dist=18~25` 与球面截图。
- **异常过程**：任何一项能力失效 → 视为阻断，不得以「暂不接入」「首轮降级」绕过。
- **后置条件**：完整能力回归全绿，线上与本地产物一致。
- **业务规则**：禁止以 iframe / 原型 HTML 替换 React 正式项目；禁止功能降级条款。
- **验收要点**：TC-20 / TC-21。
