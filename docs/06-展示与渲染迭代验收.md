- 使用实际 React 仓库作为被测项目；C 盘 HTML 仅作为共用区域的效果与算法对照，不能代替正式项目的本地验收。
- 记录提交号、构建标识、数据版本、浏览器和渲染后端；本地与线上使用相同视口和状态。
- 桌面视口：1366×768、1920×1080；窄屏视口：390×844；额外检查桌面 200% 页面缩放。
- 画面证据记录相机位置、目标、平面/球面、地形起伏、太阳角度、阴影、环境遮蔽和图层开关。
- 软件渲染用于可重复校验；至少一次用户实际 GPU 浏览器验收，二者结论分别记录。

## 二、UI 验收场景

### UI-01 首屏信息减量

前置：清洁会话进入页面，加载完成。

操作：观察全景并定位图层、画面、导览入口。

预期：工具面板默认关闭；无导览长文、来源长文和大面积图例；保留短标题、清晰工具入口及简短来源/用途提示。地图无误遮挡、文字不截断，用户不需要滚动整个页面找功能。

### UI-02 单面板与状态保留

操作：打开图层，调整省界；切换到画面并调整参数；关闭后再次打开。

预期：一次只显示一个工作面板；开关、参数及当前镜头保留；焦点可回到触发入口。关闭面板不重建地图、不重新下载地形数据。

### UI-03 图层完整与依赖

操作：逐项验证原有 8 类图层及用户可见地名分类；关闭交通并检查线名；未选省份时尝试查看市界，随后点选省份。

预期：所有原有功能可达；没有孤立线名；未选省份有明确提示；选中后市界与该省一致。关闭再打开后不重复创建对象或标注。

### UI-04 省份详情与返回

操作：从图层面板点选四川，查看详情，再返回和取消选择；重复选择另一省。

预期：详情显示现有数据；返回恢复原面板；取消选择移除高亮与对应市界，不重置镜头；缺失信息显示“暂无数据”，不生成虚构内容。

### UI-05 导览完整流程

操作：进入导览，展开讲解，上一段/下一段，播放/暂停，关闭面板，重开，退出。

预期：默认摘要不超过两行，全文可读；进度与机位一致；关闭面板后播放状态仍可见、可暂停；退出停止推进并移除导览压暗，不清空用户图层设置。

### UI-06 导览与主动浏览冲突

操作：自动导览中旋转、平移、缩放、切换范围、点选省份。

预期：主动操作暂停自动推进，不出现镜头被抢回；选省可进入详情；视图过渡连续点击时以最后有效操作为准，不留下半平面半球面状态。

### UI-07 帮助、图例和用途说明

操作：切换图层，展开图例、帮助及数据说明。

预期：图例只解释当前相关要素；完整来源和原有发布限制仍可访问；技术实现词不出现在主操作流程中；不会把示意河流、夸张地形或旧数据宣称为精确实景。

### UI-08 窄屏、键盘和减少动态效果

操作：在规定视口及页面缩放下逐项操作；只用 Tab、Enter、Space、Escape 访问工具和抽屉；启用减少动态效果偏好。

预期：无横向溢出；抽屉可关闭且不覆盖全部地图；触控目标足够；焦点可见，弹层关闭后返回入口，无焦点陷阱。面板内操作不穿透为地图拖动或拾取；旋转和播放有可用停止入口。

## 三、渲染与发布验收

### R-01 同版本同机位对比

比较实际仓库本地与 CI 的构建版本、资源清单和数据图解码结果；数据图字节不同须继续比较像素、高程和掩膜差值。旧版本入口与新数据混用、冷缓存与暖缓存分别检查。仅 HTTP 200 不代表通过。

### R-02 灰斑与两层覆盖

在原截图区域，以及青藏—四川、黄土—华北、东北和亚洲图幅边缘固定机位，录制连续缩放/旋转；分别开关全球底图、阴影与环境遮蔽。平面和球面都检查。

预期：确认根因后，正常开启全部应有图层时，不再出现底图顶穿、花斑突变和闪烁；关闭底图仅作为诊断，不作为正式修复。外部全球地形和亚洲覆盖边界不能出现新洞或台阶。

### R-03 参数和采样边界

在地形起伏 1、5、16 及低太阳高度下检查阴影与几何同步；验证浮点纹理线性过滤能力与不支持时的处理；连续切换平面/球面，不出现错向光照、整片黑面和相机穿地。

### R-04 自然观感样板

使用相同数据、机位和视口对比样板预设；山脊、河谷和平原关系清晰，地形保留连续起伏，无被磨成平板的区域；未统一标定前不得标示“真实比例”。自然观感预设切换不重置省份、图层或导览进度。

### R-05 加载与异常

模拟慢网、数据请求失败、资源版本不匹配与 WebGL 不可用；检查清楚的加载/错误状态，不能把部分加载结果当成已就绪画面。连续开关面板不得导致重复网络请求。
