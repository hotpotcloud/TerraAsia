## 一、验收环境与可重复基线

| 项 | 要求 | 理由 |
|---|---|---|
| 提交与产物 | 固定 commit sha；记录 `dist/` 与 `app/public/data/` 逐文件 hash | 线上 / 本地一致性可回溯 |
| 浏览器 | 同一 Chromium 版本；**必须真实 GPU**（`--headed`） | `08` 实测 headless SwiftShader 仅 1 fps，固定 `waitForTimeout` 会截到滞后帧，不能作证据 |
| 等待方式 | rAF 帧计数（连续 N 帧稳定）后再截图 | 同上 |
| 机位 | 全景 `dist=55`、近景 `dist=18~25`、球面固定机位，用 `__ta.camAt()` 落位 | `08` 确认 `dist=18~25` 才是放大问题机位 |
| 参数 | 固定视口、`exag`、太阳方位 / 高度、图层、动画完成状态、面板折叠状态 | 同机位对照才有效 |
| 工具 | `scripts/diag-baseline.js`（扩展 `tiles()` 钩子）产出同机位截图 + `baseline.json` | 与 `07` 的证据链一致 |
| 数据 | 记录 `manifest.json` 的 `version / source / precision / hash` | 合规与精度可核验 |
| 运行模式 | 固定 `personal` 或 `public`，并记录监听地址、鉴权状态、引用来源清单 | 两种模式的验收口径不同（见 TC-15/16/17/22/23） |

**证据命名**：`shots/diag/<阶段>/<用例号>-<机位>-<视图>.png`，并附 `baseline.json`（提交、数据 hash、机位、参数、帧率、截图路径）。

## 三、用例明细

### TC-01 首屏加载与 L0 渲染（R01 · 正常）
- 前置：清空缓存，固定 commit 与数据 hash。
- 步骤：打开线上地址 → 观察加载页 → 记录首帧。
- 预期：进度条显示真实已下载字节 / 百分比；首帧地形连续完整；无空白、无「Failed to fetch」。
- 证据：加载页截图 + `baseline.json` 首帧时间与下载字节数。

### TC-02 放大触发 LOD 细化且画面连续（R01 · 正常）
- 前置：TC-01 通过；真实 GPU。
- 步骤：`__ta.camAt()` 依次落到 `dist=55 → 30 → 22 → 18`，每级等 rAF 帧稳定后截图；记录 `__ta.tiles()` 当前级别。
- 预期：级别随距离递增；山脊 / 沟谷连续；**无空洞、无矩形色块、无泡状孤岛、无灰色平面沟谷、无接缝闪白**；切换过程不回退到粗级别画面。
- 证据：四级同机位截图组 + `tiles()` 级别日志。

### TC-03 覆盖区边界与全球粗层（R01 · 边界 / 回归）
- 前置：TC-02 通过。
- 步骤：在亚洲覆盖矩形边界内外各取 3 个机位，平面与球面各测一次；对照 `07` 中「关世界层 / 只关 AO / 只关阴影」的隔离截图。
- 预期：`aOverlay` 让位判定生效，两层不共面穿插；过渡带无硬边；`__ta.probeLayers` 同点高度差不再出现翻转归属。
- 证据：边界机位截图、`probeLayers` 数值、`baseline.json`。

### TC-04 三视图切换与坐标对齐（R02 · 正常）
- 前置：派生层产物齐全；D9 坐标方案已确认。
- 步骤：依次切「地貌 / 影像 / 混合」，在全景与近景各执行一次，平面与球面各执行一次；对手工选定的 **5 个已知地标**（如城市中心 / 山峰 / 河口）核对标注与底图的对齐偏差。
- 预期：分层设色连续；阴影方向与太阳一致；无麻面 / 过度锐化；图例与视图一致；切换无跳变；**地标偏差在 `11` §3.2 约定阈值内**。
- 证据：8 组截图（3 视图 × 2 机位 × 2 模式，去重后至少 6 组）+ 5 个地标的偏差记录。

### TC-05 底图服务不可用 / 无 key（R02 · 异常）
- 前置：底图适配器已接入。
- 步骤：分别模拟「未配置 key」「鉴权 401」「配额耗尽」「超时」，各打开一次页面。
- 预期：降级为本地晕渲 + 分层设色；地形与全部交互可用；提示明确原因；**不白屏、不阻塞首帧**。
- 证据：4 组截图 + 控制台错误记录。

### TC-06 坡度角 / 坡向图层（R03a · 正常）
- 前置：派生层就绪。
- 步骤：开启坡度角 → 对照图例阈值检查若干已知坡面；开启坡向；把 `exag` 从 1 调到 16（含默认 5）。
- 预期：着色与阈值对应；**夸张比变化不改变坡度数值与着色**；图例同步；关闭后完全还原；平面 / 球面一致。
- 证据：`exag=1 / 5 / 16` 三组对照截图。

### TC-07a 等高线间隔与级别回退（R03a · 正常 + 边界）
- 前置：等高线派生层就绪。
- 步骤：开启等高线 → 读取等高距；在高 / 低级别各检查一次；人为删除某一级别的派生层后复测。
- 预期：等高距 ≥ 20 m；级别切换后等高线连续；缺层时回退到上一级别并提示，不用错误色带冒充。
- 证据：等高线截图（两个级别）+ 缺层回退截图。

### TC-07b 线路与高程剖面（R03b · 正常 + 边界）
- 前置：R03a 通过；准备测试 GPX。
- 步骤：导入 GPX → 查看剖面与累计爬升 / 下降；把 `exag` 从 1 改到 16；把线路延伸到数据缺失区；检查网络请求。
- 预期：剖面数值基于真实高程、**不受 `exag` 影响**；缺失区显示断点与「暂无数据」，不虚构高程；GPX 仅本地处理、无上传请求。
- 证据：剖面截图与数值导出、`exag` 对照、缺失区截图、网络请求清单。

### TC-08 市级图层独立开关与 LOD（R04 · 正常）
- 前置：`cities.json` 完整性校验通过（含 34 个省级行政区）。
- 步骤：不点选任何省份，直接开启「市级行政区划」→ 从全景逐步放大到近景。
- 预期：市界作为独立图层按 LOD 绘制；默认状态可配置；远景不乱线；关闭后完全消失；点选省份仍能展开该省全部市级单元（既有交互不回退）。
- 证据：开关前后截图、LOD 分级截图。

### TC-09 市级点选与属性卡（R04 · 正常）
- 前置：TC-08 通过。
- 步骤：点击 3 个不同市级单元（含直辖市 / 自治州 / 普通地级市），再点空白处。
- 预期：选中态唯一；属性卡字段与数据集一致；取消后恢复；省 / 市 / 标注三层不遮挡。
- 证据：3 组详情卡截图 + 数据集对应条目。

### TC-10 山河要素标注与详情（R05 · 正常）
- 前置：`geo-features.json` 就绪。
- 步骤：放大到近景 → 点击山峰 / 河流 / 湖泊 / 山脉各一个 → 查看字段与 `source` → 点「飞抵此处」。
- 预期：名称与属性正确且带来源；河流 / 铁路 / 公路不再是示意性折线冒充真实走向；铁路与公路标注区分；飞抵后相机与高亮正确。
- 证据：4 组详情卡截图 + 数据来源清单。

### TC-11 属性缺失与境外要素（R05 · 边界）
- 前置：构造含空字段的测试要素。
- 步骤：点击空字段要素；查看境外山河名与邻国名。
- 预期：空字段显示「暂无数据」不臆造；境外去饱和弱化、重点仍是中国；不出现错绘地名。
- 证据：截图 + 测试数据片段。

### TC-12 景区 POI 分级、聚合与筛选（R06 · 正常 + 边界）
- 前置：`poi.json` 就绪。
- 步骤：四级 LOD 逐级放大；在 POI 密集区观察标注；按类别筛选；点击聚合点。
- 预期：近景 / 超近景才出现局部景区标注；密集区聚合 / 折叠，不叠字；筛选生效且状态可复现；点击聚合点展开列表。
- 证据：四级 LOD 截图、密集区截图、筛选前后截图。

### TC-13 全局检索与飞抵（R07 · 正常 + 异常）
- 前置：`search-index.json` 就绪。
- 步骤：检索省 / 市 / 山峰 / 河湖 / 景区各一；检索不存在的词；模拟索引加载失败。
- 预期：分类结果正确、飞抵并高亮；无结果给相近建议；索引失败只影响检索、不影响地图。
- 证据：5 组结果截图 + 异常截图。

### TC-14 性能预算（R08 · 性能）
- 前置：CI 产物与线上一致；真实 GPU。
- 步骤：清空缓存加载 → 记录首屏体积、首帧时间、稳定帧率、JS 内存 → 连续缩放旋转 3 分钟 → 记录瓦片命中率与重复下载次数。
- 预期：达到 `11` §九经评审确认的阈值；无内存持续增长；无重复下载；LOD 切换无白屏。
- 测量口径（按 `11` §九）：首屏 body 总和 / `navigationStart`→首帧 rAF / 连续 60 帧均值 / 稳定 10 s 后 `usedJSHeapSize` / 命中数÷请求总数 / 同一 `(z,x,y,version)` 请求 >1 次计数。
- 证据：性能报告（数值）、`baseline.json`、网络瀑布图、`__ta.tiles()` 日志。

### TC-15 行政区划完整性与地名规范（R04/R06/R10 · 合规，两模式均执行）
- 前置：S7 数据补齐完成。
- 步骤：逐项核对 34 个省级行政区（含中国台湾、中国香港、中国澳门）与南海诸岛表达；核对国界、十段线；抽查地名括注规则；`public` 模式另核对新增标注备案清单。
- 预期：无缺失、无错绘、无错标；`cities.json` 现缺台湾省、澳门特别行政区的问题已修复；地名以依法公布数据为准。**两种模式都不放宽领土表达。**
- 证据：核对清单（逐项签字）、全图截图；`public` 另附备案清单。**任一项不通过即阻断上线。**

### TC-16 数据源、attribution 与 key（R02/R10 · 合规，按模式）
- 前置：运行模式已配置；合规基线 S1 完成。
- 步骤：检查 `manifest.source`、网络请求域名、页面左下角 / 「关于」；核对 key 配置方式与仓库是否含 key。
- 预期：
  - `public`：仅白名单服务（腾讯 / 高德 / 百度 / 天地图）；**无 Google / Apple / Bing 海外 / 直连海外 OSM / Mapbox / Leaflet+OSM 请求**；左下角有审图号（有效期两年内）；商业 / 公开使用走服务端代理。
  - `personal`：允许 OSM / Mapbox / Bing / 天地图等；每家底图有正确 attribution 与 ToS 链接；**Google / Apple 未被接入自研引擎**（如接入则判不通过）；仓库与产物中无可用 key。
- 证据：网络请求清单、页面截图、「关于」截图、`git grep` key 检查记录。

### TC-17 精度声明与免责声明（R03a/R03b/R10 · 合规，按模式）
- 前置：`verify_compliance.py` 通过。
- 步骤：核对 `manifest.precision`、等高距、影像分辨率；查看坡度 / 线路功能附近文案与「关于」。
- 预期：
  - `public`：平面精度不优于 10 m、高程精度不优于 15 m、等高距 ≥ 20 m。
  - `personal`：不受公开精度上限约束，但**必须标注数据来源与实际精度**，不得声称优于数据本身；不得使用涉密测绘成果。
  - 两种模式：显著免责声明「不替代专业雪崩预报与现场判断」；不承诺导航 / 救援安全。
- 证据：精度声明文件、页面截图。

### TC-18 资源失败的错误提示（R08 · 异常）
- 前置：可模拟 404。
- 步骤：分别让一个瓦片、一个数据集、`manifest.json` 返回 404 / 损坏内容。
- 预期：明确显示失败资源路径与原因；保留上一级别画面；可重试；**禁止只显示「初始化失败：Failed to fetch」**（用户 2026-11-09 明确反馈过该问题）。
- 证据：3 组异常截图 + 控制台记录。

### TC-19 标注 LOD、避让与图例（R09 · 正常 + 边界）
- 前置：全图层开启。
- 步骤：四级 LOD 各截取一次；折叠 / 展开面板；在标注密集区观察；开关任意 3 个图层看图示变化。
- 预期：远景读地貌、近景读城市 / 景区；撞车避让生效不叠字；面板折叠时裁切同步解除；图例只列当前可见图层；无「永远显示、无法关闭」的元素。
- 证据：LOD 截图组、图例联动截图。

### TC-20 平面 / 球面双模式与全能力回归（R11 · 回归）
- 前置：`07` / `08` 基线可复跑。
- 步骤：按 `08` 的完整能力清单逐项执行：平面 / 地球切换、全球地形、光照阴影、AO、导览六步、省份点选、夸张滑块、**15 个图层 / 标注开关**、指北针、自动旋转、进度条、球面缩放连续、近景无空洞。
- 预期：**全部通过且无功能降级**；近景 `dist=18~25` 无泡状花斑；球面无空洞；线上与本地同机位画面一致。
- 证据：`scripts/diag-baseline.js` 全套截图 + `baseline.json` + 逐项勾选表。

### TC-21 线上与本地产物一致性（R11 · 回归）
- 前置：CI 部署完成。
- 步骤：拉取线上 `index.html`、`assets/`、`app/public/data/` 全部文件，与本地 `dist/` 逐文件比对（必要时解码比对像素）。
- 预期：入口标识一致、hash 一致；不一致项必须定位到具体发布版本并说明原因，不能笼统归为「CI 问题」。
- 证据：比对报告（文件名、大小、hash、结论）。

### TC-22 非公开性验证（R02/R10 · 合规，仅 `personal`）
- 前置：`personal` 模式已启用；D11 已拍板。
- 步骤：
  1. 从外网（非本机、非内网）尝试访问站点与原公网端口；
  2. 检查是否存在公开链接、搜索引擎收录、无鉴权可访问的静态资源；
  3. 检查 DNS / 反代 / 防火墙规则。
- 预期：外网不可访问，或必须通过鉴权；无公开分享链接；无搜索索引；`personal` 模式启动日志记录当前监听地址与鉴权状态。
- 证据：外网访问失败截图 / 401 截图、端口与防火墙配置、日志片段。
- 说明：**本用例不通过时，`personal` 模式不成立，必须转入 `public` 模式的全部合规要求。**

### TC-23 底图 ToS、可达性与降级（R02 · 异常 / 合规）
- 前置：至少配置 1 个 `personal` 可选底图（如 OSM 自托管或 Mapbox）。
- 步骤：分别模拟「无网络」「key 失效 / 401」「配额耗尽」「域名不可达」「厂商条款禁止缓存」五种情况；检查是否发生批量下载或离线打包。
- 预期：五种情况均降级本地晕渲、不白屏、提示具体原因；无批量下载 / 离线缓存行为；「关于」显示 attribution 与 ToS 链接；Google / Apple 未被接入自研引擎。
- 证据：5 组截图 + 网络请求清单 + 代码检查记录。

## 四、异常与边界专项清单

| 场景 | 覆盖用例 | 强制预期 |
|---|---|---|
| 慢网 / 中断 / 重试 | TC-01、TC-18 | 进度可见、可重试、不重复下载、不白屏 |
| 数据缺失 / 解码失败 | TC-07b、TC-11、TC-18 | 显示「暂无数据」，不臆造、不虚构数值 |
| 底图无 key / 401 / 配额 / 超时 / 不可达 | TC-05、TC-23 | 降级本地渲染，不影响地形与交互 |
| 审图号缺失或过期（仅 `public`） | TC-16 | **阻断新增标注内容上线** |
| `personal` 模式可被公网访问 | TC-22 | **判定 `personal` 不成立**，转 `public` 或关闭访问 |
| 底图 ToS 违规（脱离 SDK / 缓存 / 批量下载） | TC-16、TC-23 | 判不通过；Google / Apple 不得接入自研引擎 |
| 标注过密 / 面板折叠 / 窄屏 | TC-12、TC-19 | 聚合避让、裁切同步、不叠字 |
| 坐标偏移（WGS-84 ↔ GCJ-02） | TC-04、TC-15 | 抽检点偏移在阈值内，标注与底图对齐 |
| 夸大比 1–16× 全区间 | TC-06、TC-07b | 派生数值不随夸张改变 |
| headless 截图 | 全用例 | 一律不作证据；必须真实 GPU + rAF 帧计数 |
