## 需求描述

1. 产品定位调整为面向**旅游、徒步、爬山等户外运动爱好者以及地理爱好者**使用，不再以教学演示沙盘为唯一目标。
2. 当前实现「太偏原型」，未达到商业级细腻程度，用户判断完善程度不到 50%；需要整体更新，而不是局部修图。
3. 地图观感要足够细腻、真实，解决高度落差与阴影观感、放大后局部细节等问题。
4. 补齐**城市（市级）划分**的表达，让用户能看清行政层级。
5. 补齐**风景名胜的局部标注**。
6. 补齐**山河的具体细节标注**，而不是示意性折线和静态文字点。
7. 开发之前必须先调研社区、论坛及其他网站，再按团队开发流程编写设计文档。
8. **审核没问题后才允许代码开发**；本轮交付物为评审文档，不得先改业务代码。
9. 前序已确认并继续生效的约束：正式项目持续使用 React（Vite + React + TS）以便长期维护；保留平面 / 地球双模式、全球地形、光照阴影及已有交互能力，不得用功能降级掩盖问题；模块化组件开发，注意架构设计；新增能力应可作为选项控制显示；重点是中国；页面加载速度与资源位置需要关注；线上涉及合规，问题须立即修复；文档与代码目录按规范组织。
10. 前序已确认并继续生效的工作方式：方案建议、已验证事实、待验证原因必须区分；禁止擅自作主、禁止编写没有依据的结论；按用户更新的文档对齐开发；代码需要及时 push。
