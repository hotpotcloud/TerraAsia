## 阅读顺序

1. 新人接手：根目录 `README.md` → `02-开发规范` → `01-产品说明` 的「视觉与数据方案」一节
2. 只改前端：`app/src/`（`data/` 底层 → `scene/` 场景 → `ui/` 面板）+ `02-开发规范` 的「前端约定」
3. 只改数据范围：`src/pipeline/prep_data.py` 顶部的 bbox 常量 + `01-产品说明` 的「尺度标定」
4. 想加地图能力（地貌区、星表、标注避让）：先看 `04-外部参考与资源`

## 文档约定

- 文件名：`两位编号-中文名.md`，编号留出插入空间（02 之后新增插 02a 或顺延）
- 一篇文档只讲一件事，超过 3 屏就拆
- 涉及"为什么这么做"的决策，写进正文而不是只留在 commit message 里——半年后没人翻 commit
- 改动代码导致文档过期时，同一个 PR 内一起改
