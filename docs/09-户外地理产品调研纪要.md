## 二、【事实】同类产品与用户真正付费的东西

### 2.1 3D 户外的定义者与它留下的真空

- **FATMAP** 用三立体卫星影像构建 **2m 高程网格** 的 3D 山体模型，2023-01 被 Strava 收购，**2024-10-01 独立 App 与网站关闭**。[R2][R3][R4]
- 迁移是残缺的：路线只迁移了标题、描述、线形；**坡度等级、照片、Waypoints、Adventures、Guidebooks 无法迁移**；**离线地图、国家地形图册、实时雪况 / 雪道信息没有进入 Strava**。[R3][R4]
- 由此产生持续至今的用户外溢（Whympr / Outmap / NomadTracks / onX Backcountry 承接）。[R3][R4]

**社区原话里最关键的判断**（Outmap 的 FATMAP 替代指南）：用户真正问的不是「哪个 App 有地图」，而是「哪个 App 能让我**读懂陡坡、在 3D 里规划一条线、并把它带到离线**」；并明确指出 **"a 30m model smooths out the short, steep rolls that cause most trouble"**——30m 级 DEM 会抹掉最危险的短陡坡。[R4]

同一篇给出选型的五条用户判据：① 可旋转 / 可测量 / 可画线的 3D（不是 3D 预览）；② 由高分辨率高程生成的**坡度角图层**；③ 离线包要包含坡度着色、影像、3D 而不只是底图；④ 大屏规划 → 手机同步；⑤ GPX 导入导出。[R4]

> 【推导】「3D 好看」不是产品，**3D 绑定决策信息（坡度 / 坡向 / 离线 / 剖面）** 才是。这正是当前 TerraAsia 缺失的部分，也是用户说的「像初中生用的」的实质。

## 三、【事实】社区 / 论坛里可直接复用的工程经验

### 3.1 山体阴影不是「开个灯」就细腻

GIS StackExchange 关于 relief shadow 的回答给出的实操参数：[R5]

- `gdaldem hillshade` 的 `-az`（方位角，默认 315）、`-alt`（高度角）、`-z`（垂直夸张）、`-s`（垂直/水平单位比，经纬度数据用 111120）；
- `-combined`（坡度 + 斜照组合）、`-multidirectional`（GDAL 2.2+，225/270/315/360 四方向合成）；
- **`gdaladdo` 建金字塔**；社区明确指出「难看」通常来自 **z 夸张过大 + 分辨率过高**，以及缺少 overviews / 插值泛化。

SuperMap 与 CSDN 的中文实践同样强调：**三维晕渲图 + 分层设色叠加**（DEM 图层设透明度/亮度叠在晕渲之上），方位角 315 / 高度角 45 是默认起点，「渲染与阴影」模式更真实，高程缩放倍数需按区域反复调。[R9]

CSDN DevPress 的 Three.js DEM 全链路文章给出的专题层做法：离线预算 `slope / aspect / roughness / relief / TWI / ridge-valley-flow-watershed mask`，渲染层支持 `elevation / slope / aspect` 与 `contour / flow / watershed` 混合着色，并给出帧率 45–75 FPS、内存 180–360 MB、首帧 3–14 s 的**开发环境观测值**。[R10]

> 【推导】TerraAsia 现在把「细腻度」压在单一高度场 + 程序化色带上，缺少**离线预计算的晕渲 / 坡度 / 等高线专题层**。这是差距的技术根因，不是调参就能补上的。

### 3.2 地形瓦片格式与引擎选型

综合检索摘要（配合 CesiumJS 中文教程 [R15]）：

| 格式 | 特点 | 适用性 |
|---|---|---|
| **Quantized-Mesh** | 四叉树 LOD（远粗近精、按需加载）、**内置顶点法线**、附带水面掩码、二进制高度压缩 | 商业级 3D 地形事实标准，需 `cesium-terrain-builder` + `layer.json` |
| Heightmap（灰度 PNG） | 结构简单、体积大、精度固定、无内建 LOD | 小范围 / 离线快照 |
| Raster-DEM（MapLibre / Mapbox 编码） | 快速上线，最高约 zoom 14（赤道 ≈10m） | 授权与配额受制于供应商 |

引擎侧：CesiumJS **Apache 2.0 商用免费**、原生球体与地形；MapLibre GL JS BSD-3 开源、轻量；Mapbox GL JS v2 起专有许可。需注意 ion 内置默认 token 会随版本失效（**综合检索摘要，未取得一手证据，待核实**），生产必须自有账号。[R13][R15]

> 【建议】TerraAsia 是否迁移 CesiumJS 是**架构级决策**，涉及重写已修复的渲染链路（见 `07` / `08` 的证据链）。本纪要只列出选项，**不替用户决定**。

## 四、【事实】合规与数据源边界（公开 vs 自用）

### 4.1 法规原文

- 《公开地图内容表示规范》第十九条：**表现地为我国境内的地图，平面精度应当不优于 10 米（不含），高程精度应当不优于 15 米（不含），等高线的等高距应当不小于 20 米（不含）**；依法公布的高程点可公开表示。第十六条：重要地理信息数据以依法公布的数据为准。[R7]
- 《地图审核管理规定》第二十七、二十八条：互联网地图服务应在**地图页面左下角显著标注审图号**；**审图号有效期两年**，到期重新送审；审核通过的互联网地图服务**每六个月将新增标注内容及核查校对情况备案**；第二十三条：批准核发审图号。[R6]
- 《测绘法》体系：从事测绘活动须取得测绘资质；地图数据服务器须境内；涉密基础测绘成果需审批且不得公开分发。[R8]
- **适用范围备注**：上述审图号 / 备案义务针对**公开发布的互联网地图服务**；个人自用、不对外提供访问的本地工具不构成该服务，但**领土表达与内容安全要求不变**（见 §4.2）。这不是法律意见，正式定性请咨询有资质单位。

### 4.2 数据源约束：区分「公开发布」与「个人自用」

【事实】合规基线（`geo-map-compliance-guard`）面向**公开发布的互联网地图服务**：禁用 Google Maps、Apple Maps、Bing 海外版、直连海外 OSM 瓦片、Mapbox、Leaflet+OSM，仅允许腾讯地图 / 高德 / 百度 / 天地图，未指定时默认腾讯地图。

【关键判定】**「非商业」不等于「非公开」**。当前项目部署在公网 `http://119.29.189.103:8159/`，无鉴权、不特定人可访问，在监管口径下仍属公开可访问的地图服务。要做成「仅自用」，必须先改变可访问性（下线公网 / 仅内网 / 加访问控制），否则不能以「自用」为由跳过审图与领土表达要求。

【自用模式可放宽】在**确实不公开**的前提下：

- 底图 / 瓦片可选 Google、Apple、Bing、OSM、Mapbox 等，用于个人查看与开发调试；
- 境外 DEM / 影像可直接使用（如现有 Terrarium），不必先替换；
- 审图号与六个月备案可不办理（不构成公开发布的互联网地图服务）。

【不可放宽（与是否商业无关）】

- 国界、中国台湾、中国香港、中国澳门、南海诸岛表达必须正确；不得把中国台湾 / 中国香港 / 中国澳门当作国家；
- 不标注军事禁区、涉密实体；不公开他人位置数据；
- 各厂商 ToS 仍须遵守——**自用不等于可以违反服务条款**。

【厂商 ToS 与可达性（自用也要看）】

| 源 | 坐标 | 主要限制 | 国内可达性 |
|---|---|---|---|
| Google Maps | WGS-84（中国区 GCJ-02） | 瓦片仅限 Google Maps SDK 内使用，**禁止脱离 SDK、禁止缓存 / 离线** | 不可用 |
| Apple Maps | WGS-84 / GCJ-02 | MapKit JS 需 token，瓦片不得脱离 MapKit | 可用，需 token |
| Bing Maps | WGS-84 / GCJ-02 | 需 key 与配额，中国区有偏移 | 可用 |
| OSM 公共瓦片 | WGS-84 | Tile usage policy 禁止批量 / 离线，需 attribution、有限速 | 慢、不稳定 |
| OSM 自托管 | WGS-84 | 需自建 tile server 与存储 | 可控 |
| Mapbox | WGS-84（中国区可选 GCJ-02） | token、按 MAU / 请求计费，免费额度有限 | 可用，需网络条件 |

【建议】自用优先级：**天地图 / OSM 自托管 > Mapbox 或 Bing 影像 > Google（仅本地实验，不缓存、不对外）**。原因不是合规，而是 ToS 与可达性：Google 最容易被封、条款最严，Apple 的瓦片脱离 MapKit 使用同样违规。

> 【事实 + 风险，按模式分档】当前管线从 `s3.amazonaws.com/elevation-tiles-prod/terrarium` 拉取 z6 / z4 高程瓦片（`src/pipeline/prep_data.py:82`、`prep_world.py`）。
> - **自用模式**：可直接保留，只需在「关于」标注来源与精度；
> - **公开发布**：不在白名单内，必须先替换，属 P0 阻断项。

> 【推导】国内公开版做 3D 地形，**精度瓶颈是许可而不是技术**：以合规精度 + 优秀可视化 + 分析功能取胜；超高精度需求只能走 B 端审批 + 私有化，不进入本轮范围。自用模式不受此限，但也不应以「自用」为名公开发布。

### 4.3 安全责任

RealityMaps / 两步路均标注「不替代专业雪崩预报与现场判断」。[R1][R11] 若产品提供坡度、地形难度判断，必须显著免责，且不承诺救援 / 导航安全功能。
