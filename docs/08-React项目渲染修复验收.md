## 一、基线与根因证据

- 使用 D 盘正式 React 工程作为被测项目，C 盘 HTML 仅作为已知正常表现和共用逻辑的对照。
- 记录提交、构建、输入数据、视口、浏览器/GPU、相机、视图模式、起伏、光照、图层和动画状态。C、D 的能力差异与参数差异单独说明，不能据此直接归因 CI 或 React。
- 对同一亚洲区域核对高程、掩膜、阶梯、投影、UV、几何和法线；数据图必须比较解码结果，字节不一致本身不判定损坏。
- 同机位隔离世界层、阴影、AO 等只作为定位实验；保留隔离前后证据，并将尚未复现的原因标为待验证。
- 每项修复有具体原因、修改位置及前后对照；不得把推测、历史记录或未成功执行的截图脚本当成已验证结果。

## 二、完整渲染效果

- 在原截图区域、青藏—四川、黄土—华北、东北、海岸及亚洲覆盖边界，分别检查全景和近景；连续缩放、旋转和平移无异常灰斑、地形穿插、闪烁、断层和相机穿地。
- 全球与亚洲地形同时显示；精细覆盖区不被粗地形顶穿，覆盖边缘无空洞或突兀台阶。不能以永久关闭世界层或隐藏区域通过验收。
- 平面、全球球面及往返切换均正常，全球其他区域仍可浏览；连续切换不会停在无效中间态。
- 在原有起伏范围及太阳方向、高度范围内检查地形与阴影同步；阴影与环境遮蔽分别正常，恢复完整效果后无异常花斑或整片黑面。
- 检查纹理采样、法线、光照和颜色链路；任何参数调优都须确认山脊、河谷和平原关系仍合理，不能通过磨平地形或统一提亮掩盖缺陷。
- 在用户实际 GPU 浏览器和可重复的软件渲染环境分别记录结果；自动化通过不能代替最终自然观感确认。

## 三、React 与交互维护性

- 正式页面继续使用 React，沿用现有模块分层；不以嵌入原型 HTML、维护两套业务状态或复制隐藏控件作为验收实现。
- React StrictMode、组件卸载和重挂载不产生重复场景、渲染循环、事件监听或资源泄漏；面板切换、选择省份和调参不重载地图。
- 逐帧相机和动画不触发 React 全树更新；参数、图层、导览和详情状态一致。
- 省界、市界、十段线、海岸/国界、河流、铁路、公路和地名分类均可操作，交通与线名、市界与选省的依赖正确。
- 点选、取消选择、详情返回、导览步进/播放/暂停/退出、范围切换及自动旋转完整可用，主动浏览与自动镜头不冲突。

## 四、UI 与功能可达

- 首屏文字精简，说明按需展开；图层、画面、导览集中组织，原功能没有因换入口丢失。
- 平面/球面入口和太阳、阴影、AO 等画面参数保留；低频设置可折叠，但不能删除、永久禁用或无限延期。
- 1366×768、1920×1080、390×844 以及桌面 200% 缩放下检查控件、标注、面板和图例；焦点可见，键盘可操作，面板事件不穿透地图。
- 来源与用途说明完整可访问，不将示意矢量或未经统一标定的夸张比例宣称为精确实景。

## 五、构建和线上一致性

- 干净 checkout 与连续构建均可生成完整正式产物；缺失瓦片、异常掩膜、数据损坏和资源不匹配能被识别，不静默带入发布。

- 本地和线上使用同一份已验证产物；冷/暖缓存下代码与数据版本匹配。资源、接口和 HTTP 成功只是检查的一部分。
- 在真实部署地址复测完整渲染和交互；记录实际结果、截图、未通过项和用户视觉确认，不提前标注完成。
